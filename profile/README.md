Welcome to the Obol GitHub!


The Obol GitHub is a collection of software which enables Obol Distributed Validators (DVs), and the Obol Stack. This includes repositories for [documentation](https://github.com/ObolNetwork/obol-gitbook/), the DV middleware client [Charon](https://github.com/ObolNetwork/charon), tools for running a DV node or DV cluster via Docker, the Obol Stack, and more. Please see the links below. 

## About Obol

The Obol Collective is a collection of tools, teams, and communities dedicated to scaling Ethereum by strengthening the security, resilience, economy, and decentralisation of the network; through the development and deployment of Distributed Validators, the Obol [Stack](https://obol.org/stack), and the Obol Agent framework. The Distributed Validator middleware client, [Charon](https://docs.obol.org/learn/charon/intro), boosts the security, resilience, and decentralisation of the Ethereum validator network by enabling “[squad staking](https://squadstaking.com)”. The Obol [Stack](https://docs.obol.org/obol-stack/obol-stack) boosts the economy and decentralisation of the Ethereum application layer, by allowing users to run Ethereum applications locally, and to interact with them and the chain by leveraging their Obol Agents.
